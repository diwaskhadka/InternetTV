Madhyasthata for Windows
========================

Run:  Madhyasthata.exe   (double-click it; no installer, no .NET install needed)

Keep Madhyasthata.exe, iptvcore_ffi.dll and the libvlc folder together.
You can move the whole folder anywhere (Desktop, C:\Apps\Madhyasthata, a USB stick).

"Windows protected your PC"?  The app is not code-signed yet.
Click  More info  ->  Run anyway.

First start: add your Xtream Codes login or M3U playlist URL.
Madhyasthata ships with no channels.

Keys: Enter / double-click = play, F11 = fullscreen (Esc to leave),
Space = pause, PgUp/PgDn = change channel, Ctrl+Left/Right = seek 10 s,
Ctrl+F = search, right-click = favorite.

Problems? Send the files in  %LOCALAPPDATA%\Madhyasthata\  (error.log, app.log).
